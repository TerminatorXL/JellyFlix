The settings below are handed to the web client as window.JELLYFLIX_ADDON_CONFIG. Saving takes effect on the next page load — no server restart.

Off means the script tag is not injected into the web client at all.

Pause info card

Pause playback and the film or series logo, the episode title and the synopsis fade in over the frame.

A pause shorter than this is almost always a seek. 350 is a good default; raise it if you scrub a lot.
"21 min left", read from the player. Hidden below one minute.

CSS hooks

These put information into the page for a stylesheet of your own to render. With no matching CSS they do nothing at all.

data-jfx-row="continue-watching" on every home row, so CSS can address a row by name instead of by position.
--jflix-scroll: 0…1 on <html>, for an app-bar scrim that ramps smoothly on TV browsers. Read it as var(--jflix-scroll, 0).
data-jfx-overview, -genres and -runtime on home cards, for a CSS hover panel built with content: attr(). Costs one extra API call per batch of cards, so it is off by default.
Writes [JellyFlix] tracing to the browser console.

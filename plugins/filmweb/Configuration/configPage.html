Filmweb

Filmweb.pl as a metadata source for films and series. Switch it on per library: Dashboard → Libraries → the library → tick Filmweb under the metadata downloaders and the image fetchers, and drag it above the others if it should win. Then use Refresh metadata, or Identify on a single title. Saving here takes effect on the next refresh — no restart.

Off names the item with Filmweb's Polish title and keeps the original one in the "Original title" field.
Filmweb does not publish character names, so its actors come without their roles. Jellyfin takes an item's people from the first downloader that has any: if Filmweb is above TMDb and you want TMDb's cast with roles, switch this off.
Each actor costs one more request to Filmweb, so a library scan gets slower as this grows. 0 brings in the directors only.
The average of Filmweb's critics, on Jellyfin's 0–100 scale. The users' average always becomes the community rating.
Filmweb serves stills at most 900 px wide — below Jellyfin's default minimum for a backdrop, so they show up in the image picker but are not downloaded on their own unless you lower that minimum in the library's settings.
